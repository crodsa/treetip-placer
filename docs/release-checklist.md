# GitHub release checklist

Do not publish until every applicable item is complete.

- [ ] The complete interface and documentation are English-only.
- [ ] Unit, integration, and reproducibility tests pass in continuous integration.
- [ ] At least one redistributable synthetic fixture exercises the complete workflow.
- [ ] Real aligned-sequence validation has been performed locally with permitted data.
- [ ] Placement accuracy, support calibration, runtime, and memory benchmarks are documented.
- [ ] Critical and high-severity defects are resolved.
- [ ] Newick, Nexus, TSV, JSON, and JPlace outputs have been inspected with compatible downstream software.
- [ ] Dependencies and licenses are reviewed.
- [ ] A public license has been selected and added as `LICENSE`.
- [ ] `README.md`, `CITATION.cff`, `CONTRIBUTING.md`, `CHANGELOG.md`, and issue templates are complete.
- [ ] No private genomes, alignments, identifiers, credentials, or restricted database material are tracked.
- [ ] GitHub Actions runs linting, tests, and a smoke placement.
- [ ] The repository visibility and destination have been confirmed.
- [ ] A version tag and release notes have been prepared.
